# Boilerplate Skills Plugin

A collection of example skills for GitHub Copilot CLI.

## Installation

This plugin is available through the Codex marketplace.

## Skills Included

### 1. Hello World
- **Name**: hello-world
- **Description**: A simple greeting skill that demonstrates basic functionality
- **Usage**: `copilot skill run hello-world`

### 2. Deploy
- **Name**: deploy
- **Description**: Deploy your project to production with Copilot assistance
- **Usage**: `copilot skill run deploy`

### 3. Analyze Code
- **Name**: analyze-code
- **Description**: Analyze code quality, performance, and security issues
- **Usage**: `copilot skill run analyze-code`

## Creating New Skills

To add new skills to this plugin:

1. Create a new directory in `skills/`
2. Add a `SKILL.md` file with frontmatter and documentation
3. Follow the format used in existing skills
